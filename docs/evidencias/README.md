# Evidencias de pruebas

Registro de lo que se probó a mano o en dispositivos, para que un tutor o alguien nuevo pueda reconstruir qué se probó, cuándo, con qué y qué salió, sin explicaciones orales (Estrategia de Pruebas v4, gestión de evidencias). Mismo criterio que `docs/evidencias/` del repo web.

| Tipo | Nombre del archivo | Plantilla |
|---|---|---|
| Sesión exploratoria del sprint | `EXP-sprint-N-AAAA-MM-DD.md` | [`plantilla-exploratoria.md`](plantilla-exploratoria.md) |
| Funcionalidad core (FC-NN) en dispositivo o Test Lab | `FC-NN-AAAA-MM-DD.md` | Encabezado de la plantilla exploratoria + tabla de casos |

Las capturas van en `capturas/<nombre-del-registro>/`. Cada registro enlaza la HU o el FC que lo originó y, si hay hallazgos, los tickets de Jira.
